Welcome to Cloud Computing

Cloud computing provides computing resources such as storage, servers, databases and applications through the Internet.

Cloud Service Models

IaaS

Infrastructure as a Service provides virtual machines, storage and networking resources.

PaaS

Platform as a Service provides a platform for developing and deploying applications.

SaaS

Software as a Service provides software applications through the Internet.

Cloud Deployment Models

Public Cloud

Cloud resources are provided to the public through the Internet.

Private Cloud

Cloud infrastructure is dedicated to a single organization.

Hybrid Cloud

Combination of public cloud and private cloud.

Community Cloud

Cloud infrastructure shared by organizations having common requirements.

About Cloud Computing

Cloud computing allows users to access computing resources whenever required without maintaining all the hardware locally.

  • On-demand resources
  • Scalability
  • Cost efficiency
  • High availability
  • Internet-based access
